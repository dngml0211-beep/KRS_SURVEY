# images (이해용 이미지 자리)

문항이나 선택지에 이미지를 넣고 싶을 때 이 폴더에 파일을 두고, `js/questions.js`에서 경로만 연결하면 됩니다.
경로가 비어 있거나 파일이 없으면 화면에 아무것도 안 나오니(자동 숨김) 지금은 자리만 잡아둔 상태입니다.

## 연결 방법

**문항 이미지** — 해당 문항 객체의 `image`:
```js
{ num: 5, key: "재밌던책", ..., image: "images/q5_books.png", ... }
```

**선택지 이미지** — 해당 선택지의 `img`:
```js
options: [
  { label: "재미있었다", emoji: "😄", img: "images/opt_happy.png" },
  ...
]
```

## 권장 사항
- 형식: PNG / JPG / WEBP
- 문항 이미지 폭: 900px 내외 (가로 꽉 차게 표시됨)
- 선택지 이미지: 정사각형 권장 (52×52로 축소 표시)
- 파일명은 영문·숫자·언더스코어 사용 (예: `q6_k1_book.png`)
